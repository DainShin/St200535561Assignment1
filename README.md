# US Unemployment Chart

🇺🇸 U.S. Average Unemployment Rate Visualization Java Application (1951–2023)
This application is a Java-based data visualization tool that displays the average unemployment rates in the United States from 1951 to 2023.
Users can explore unemployment trends over the years and analyze statistics by age groups through tables, bar charts, and line graphs.

Key Features:
1) Visualization of annual overall unemployment rates
2) Visualization of gender unemployment rates
3) Analysis of unemployment by age groups (ages 16–17, 16–19, 25 and over, etc.)
